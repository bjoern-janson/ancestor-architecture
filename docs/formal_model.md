# Ancestor Architecture: Formal Model

## Abstract

The Ancestor Architecture models intelligence as a recursive capability-generating system.

Unlike optimization frameworks that maximize immediate performance, this model evaluates intelligence by its ability to:

1. build useful representations of reality
2. update those representations when reality disagrees
3. expand agency across agents and generations
4. preserve diversity and future possibility
5. avoid creating dependency traps

The central hypothesis:

\[
\boxed{
\text{Higher intelligence} =
\text{higher capability generation}
}
\]

not merely:

\[
\text{Higher intelligence} =
\text{higher task performance}
\]

---

# 1. Core Intelligence Function

The epistemic component is defined as:

\[
I \approx M_q \times V_u \times P_M
\]

Where:

| Variable | Meaning |
|---|---|
| \(M_q\) | Model quality |
| \(V_u\) | Update velocity |
| \(P_M\) | Model permeability |

---

## 1.1 Model Quality

A model is a compression of reality.

\[
M_q =
\frac{\text{Useful preserved structure}}
{\text{Complexity required}}
\]

A model succeeds when it removes irrelevant information while preserving structures necessary for prediction and action.

The objective is not maximum information retention.

The objective is maximum useful compression.

---

## 1.2 Update Velocity

Update velocity measures how quickly a system converts error into improved models.

\[
V_u =
\frac{\Delta M}{\Delta t}
\]

Where:

- \(\Delta M\) = improvement in model structure
- \(\Delta t\) = time required for revision

A system with high accuracy but zero update velocity becomes increasingly fragile as reality changes.

---

## 1.3 Model Permeability

Permeability measures resistance to correction.

\[
P_M =
\frac{\text{Ability to absorb model failure}}
{\text{Resistance to revision}}
\]

High permeability systems:

- detect errors
- revise assumptions
- incorporate contradictions

Low permeability systems:

- defend existing models
- reject conflicting evidence
- increase update cost

---

# 2. Agency Vector

Intelligence must not only improve internal models.

It must expand the ability of agents to act.

The agency equation:

\[
A_{net}=C \times D \times S \times E
\]

---

## 2.1 Capability

\[
C = \text{problem-solving capacity}
\]

Capability measures whether an agent can successfully transform goals into outcomes.

---

## 2.2 Diversity

\[
D = \text{variation of possible approaches}
\]

Diversity prevents optimization collapse into monoculture.

A system with maximum capability but zero diversity becomes brittle.

---

## 2.3 Sovereignty

\[
S = \text{ability to select and revise goals}
\]

Sovereignty prevents agents from becoming passive components inside another optimization process.

---

## 2.4 Exploration

\[
E = \text{ability to discover unknown solution spaces}
\]

Exploration preserves the possibility of discovering concepts outside the current model.

---

# 3. Recursive Agency Dynamics

Agency evolves through:

\[
\Delta A_{self}
\rightarrow
\Delta A_{others}
\rightarrow
\Delta A_{future}
\rightarrow
\Delta A_{self}^{next}
\]

The system is stable only if agency creation becomes regenerative.

---

## 3.1 Self Agency

\[
\Delta A_{self}>0
\]

The agent increases:

- internal capability
- self-regulation
- independence
- adaptability

Without this layer, service becomes self-erasure.

---

## 3.2 Other Agency

\[
\Delta A_{others}>0
\]

The agent transfers capability outward.

Examples:

- teaching
- tools
- institutions
- infrastructure
- shared knowledge

---

## 3.3 Future Agency

\[
\Delta A_{future}>0
\]

The system creates conditions for future agents to exceed current limitations.

Success is measured by succession, not preservation.

---

# 4. Ancestor Reward Function

The alignment objective:

\[
R_{ancestor}
=
R_{task}
+
\alpha\Delta A_{human}
+
\gamma\Delta A_{human}^{next}
-
\beta D_{dependency}
\]

---

## Components

### Task Performance

\[
R_{task}
\]

Immediate usefulness.

The system must still solve real problems.

---

### Human Capability Growth

\[
\Delta A_{human}
\]

Measures whether the user becomes more capable after interaction.

---

### Future Capability Transfer

\[
\Delta A_{human}^{next}
\]

Measures whether the user can increase capability in others.

---

### Dependency Penalty

\[
D_{dependency}
\]

Measures unnecessary reliance.

Examples:

- declining independent reasoning
- inability to perform without assistance
- reduced exploration
- skill decay

---

# 5. Amplification vs Substitution

The central evaluation problem:

\[
Output \uparrow
\]

does not necessarily imply:

\[
Agency \uparrow
\]

---

## Substitution

\[
Performance \uparrow
\]

while:

\[
A_{self}\downarrow
\]

The system produces results while degrading internal capability.

---

## Amplification

\[
Performance \uparrow
\]

and:

\[
A_{self}\uparrow
\]

The system improves both outcomes and future independence.

---

# 6. Counterfactual Evaluation

The primary test:

\[
\boxed{
\text{Remove the system. Measure what remains.}
}
\]

Evaluation:

\[
\Delta C =
C_{after}
-
C_{before}
\]

Where:

- \(C_{after}\) = independent capability after interaction
- \(C_{before}\) = independent capability before interaction

A successful ancestor system leaves positive capability after removal.

---

# 7. Evolutionary Stability Condition

A stable intelligence system requires:

\[
C \times D \times S \times E > 0
\]

and:

\[
\Delta A_{future}>0
\]

A system that increases capability while destroying diversity or sovereignty eventually stagnates.

---

# 8. Model Replacement Mechanism

A living model must contain its own replacement pathway.

\[
\boxed{
\text{Current model}
\rightarrow
\text{failure detection}
\rightarrow
\text{revision}
\rightarrow
\text{higher model}
}
\]

The strongest system is not one that cannot be replaced.

It is one designed to generate superior successors.

---

# 9. Main Hypotheses

## H1: Update Velocity Hypothesis

A lower-accuracy system with higher update velocity can outperform a higher-accuracy static system over expanding environments.

---

## H2: Dependency Hypothesis

Systems optimized only for immediate utility increase dependency risk.

---

## H3: Ancestor Hypothesis

The highest-performing intelligence architecture maximizes future capability generation rather than current dominance.

---

## H4: Diversity Hypothesis

Maintaining independent variation increases long-term adaptability.

---

\[

Ancestor\ Intelligence
=
(M_q \times V_u \times P_M)
\times
(C \times D \times S \times E)
\times
(\Delta A_{self}
\rightarrow
\Delta A_{others}
\rightarrow
\Delta A_{future})
}
\]

Subject to:

\[
\boxed{
Capacity\ preservation > Outcome\ preservation
}
\]

The terminal objective:

\[
\boxed{
\text{Create more centers of intelligence without requiring one permanent center.}
}
