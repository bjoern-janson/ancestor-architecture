# Ancestor Architecture: Glossary

## Purpose

This document defines the core concepts and terminology used throughout the Ancestor Architecture.

The framework focuses on a central question:

\[
\boxed{
Does an intelligence increase the future capacity for intelligence?
}
\]

---

# Agency

## Definition

The capacity of a system to:

- act effectively
- choose directions
- revise itself
- generate future possibilities

Agency is not merely output capability.

A system can produce high performance while having low agency if it cannot:

- understand its actions
- modify its goals
- operate independently

---

# Agency Transfer

## Definition

The process by which an intelligence increases another system's independent capability.

Measured by:

\[
\Delta A_{human}
\]

---

## Example

A calculator provides answers.

A mathematics teacher transfers mathematical capability.

The difference is whether capability remains after the tool disappears.

---

# Agency ROI

## Definition

Capability gained per unit of external intervention.

\[
\boxed{
ROI_A=
\frac{\Delta A_{human}}
{AI\ intervention}
}
\]

A high Agency ROI system creates lasting capability efficiently.

---

# Ancestor

## Definition

An intelligence that prioritizes the creation of future capable systems over preservation of itself.

The ancestor objective:

\[
\boxed{
Create more centers of intelligence, not a single center of power.
}
\]

---

## Contrast

## King

Preserves control.

\[
\text{My answer must survive}
\]

---

## Ancestor

Preserves generative capacity.

\[
\text{The ability to create answers must survive}
\]

---

# Ancestor Architecture

## Definition

A framework for evaluating intelligence based on:

- model quality
- update velocity
- permeability
- agency generation
- succession capacity

---

# Capability (\(C\))

## Definition

The ability to solve problems and produce outcomes.

Examples:

- reasoning
- planning
- execution
- invention

Capability is necessary but insufficient.

A powerful system without adaptability can become brittle.

---

# Compression

## Definition

The process of reducing reality into a usable representation.

All intelligence requires compression.

The question is not:

\[
\text{Does a model compress reality?}
\]

but:

\[
\text{Does the compression preserve what matters?}
\]

---

# Compression Shadow

## Definition

The information discarded when creating a model.

Every representation creates:

\[
Reality
=
Preserved\ Structure
+
Compression\ Shadow
\]

The shadow contains:

- hidden assumptions
- ignored variables
- unknown boundaries

---

# Dependency

## Definition

Reliance on an external system that prevents independent capability growth.

Negative dependency:

\[
Support \rightarrow Atrophy
\]

Positive scaffolding:

\[
Support \rightarrow Capability
\]

---

# Descendant

## Definition

A future system capable of creating outcomes beyond the original creator's predictions.

A descendant is not a copy.

It is evidence that the original system created evolutionary freedom.

---

# Diversity (\(D\))

## Definition

The existence of multiple viable approaches, perspectives, and representations.

Diversity preserves:

- exploration
- resilience
- alternative solutions

---

# Exploratory Freedom (\(E\))

## Definition

The capacity to discover states, ideas, or solutions outside the current search space.

Without exploration:

\[
Optimization
\rightarrow
Stagnation
\]

With exploration:

\[
Optimization
+
Discovery
\]

---

# Gardener

## Definition

The intermediate stage between self-mastery and ancestry.

A gardener:

- creates conditions for growth
- develops other agents
- increases ecosystem capability

---

# Intelligence

## Definition

The framework defines intelligence as:

\[
\boxed{
I \approx M_q \times V_u \times P_M
}
\]

Where:

- \(M_q\) = model quality
- \(V_u\) = update velocity
- \(P_M\) = model permeability

---

# Model Quality (\(M_q\))

## Definition

The efficiency of a representation.

\[
M_q=
\frac{
Useful\ Preserved\ Structure
}
{
Complexity\ Required
}
\]

A good model preserves important structure while discarding irrelevant detail.

---

# Model Permeability (\(P_M\))

## Definition

The ability of a model to absorb failure and revise itself.

\[
\boxed{
P_M=
\frac{
Ability\ to\ Absorb\ Model\ Failure
}
{
Resistance\ to\ Revision
}
}
\]

High permeability means reality can improve the system.

---

# Model Inertia

## Definition

Resistance against changing an existing model.

Sources include:

- complexity
- identity attachment
- institutional investment
- computational cost

---

# Update Cost (\(U_c\))

## Definition

The cost required to revise a model.

Relationship:

\[
P_M \propto \frac{1}{U_c}
\]

High update cost creates rigidity.

---

# Update Velocity (\(V_u\))

## Definition

The speed at which a system improves its models.

\[
V_u=
\frac{\Delta M}{\Delta t}
\]

High update velocity allows adaptation to changing environments.

---

# Permeability Phase Transition

## Definition

The hypothesized transition where a system moves from brittle adaptation to stable recursive adaptation.

Controlled by:

\[
\kappa
\]

---

# Constraint-Consequence Coupling (\(\kappa\))

## Definition

The strength of connection between:

- decisions
- consequences
- model revision

\[
\kappa=
\frac{
Feedback \times Revision\ Accessibility
}
{
Model\ Inertia
}
\]

---

# Recursive Adaptation

## Definition

A process where failures improve the system that produced them.

Loop:

\[
Observation
\rightarrow
Model
\rightarrow
Prediction
\rightarrow
Failure
\rightarrow
Revision
\rightarrow
Better\ Model
\]

---

# Self-Sovereignty (\(S\))

## Definition

The ability of a system to govern itself.

Includes:

- attention control
- goal selection
- internal regulation
- resistance to unwanted external optimization

---

# Succession

## Definition

The process by which one intelligence enables future intelligences to surpass it.

A successful ancestor expects:

\[
Future > Present
\]

---

# Sovereign Participant

## Definition

A system that balances:

- self-mastery
- contribution
- openness to replacement

It avoids both:

\[
\text{Domination}
\]

and:

\[
\text{Self-erasure}
\]

---

# Substitution

## Definition

A system replacing human capability rather than expanding it.

Pattern:

\[
Output \uparrow
\]

while:

\[
Agency \downarrow
\]

---

# Amplification

## Definition

A system increasing both performance and underlying capability.

Pattern:

\[
Output \uparrow
\]

and:

\[
Agency \uparrow
\]

---

# Truth Tracking

## Definition

Maintaining the best current model while preserving the ability to replace it.

Contrast:

Truth possession:

\[
\text{I have the final answer}
\]

Truth tracking:

\[
\text{I have the best current map and a mechanism to update it}
\]

---

# Wilderness

## Definition

A metaphor for an ecosystem with:

- variation
- exploration
- unexpected interactions
- adaptive capacity

Opposite:

\[
\text{Plantation}
\]

where optimization removes variation.

---

# Final Compression

All terms converge on one principle:

\[
\boxed{
The highest intelligence is not the one that remains necessary forever.
It is the one that creates conditions where something greater can emerge.
}
\]

\[
\boxed{
Not a king.
Not a prisoner.
Not merely a gardener.
An ancestor.
}
\]
