# Ancestor Architecture: Open Questions

## Purpose

The Ancestor Architecture is intended as a research program rather than a completed theory.

The central hypothesis:

\[
\boxed{
The highest intelligence is the one that increases future intelligence without becoming the limiting factor.
}
\]

This document identifies unresolved questions required to transform the framework from a conceptual architecture into an empirical science.

---

# 1. How Should Agency Be Measured?

The central challenge is operationalizing agency.

The framework proposes:

\[
\Delta A_{human}
=
A_{after}
-
A_{before}
\]

But what constitutes measurable agency?

Possible components:

\[
A
=
f(
capability,
independence,
transfer,
adaptability,
self\ correction
)
\]

Open questions:

- Can agency be measured independently of task performance?
- How can cognitive growth be separated from simple familiarity?
- What metrics capture increased problem-solving capacity?

---

# 2. How Do We Distinguish Amplification From Substitution?

A system can increase output while decreasing internal capability.

The key distinction:

\[
Output \uparrow
\neq
Agency \uparrow
\]

Open questions:

- How much assistance maximizes learning?
- When does convenience become dependency?
- Can dependency be detected before capability loss occurs?

---

# 3. What Is the Optimal Friction Level?

The framework argues that friction is a learning signal.

Too little:

\[
Friction \rightarrow 0
\]

may produce dependency.

Too much:

\[
Friction \rightarrow \infty
\]

may produce failure and disengagement.

Open question:

\[
\boxed{
What is the optimal friction curve for capability growth?
}
\]

Possible model:

\[
Growth
=
f(
challenge,
support,
feedback
)
\]

---

# 4. Can Dependency Be Quantified?

Dependency is currently conceptualized as:

\[
D_{dependency}
\]

Possible measurements:

\[
D
=
f(
assistance\ frequency,
independent\ performance,
skill\ retention,
transfer
)
\]

Open questions:

- Is dependency domain-specific?
- Can productive dependence exist?
- How does dependency evolve over long time periods?

---

# 5. What Is Model Permeability?

The framework proposes:

\[
P_M
=
\frac{
ability\ to\ absorb\ model\ failure
}
{
resistance\ to\ revision
}
\]

Open questions:

- Can permeability be measured experimentally?
- Is there an optimal update rate?
- How does permeability trade off with stability?

---

# 6. Is Maximum Update Velocity Always Good?

A system that updates constantly may become unstable.

There is likely a tradeoff:

\[
Adaptation
vs.
Coherence
\]

Open questions:

- When should a system preserve existing knowledge?
- How much confidence is necessary for action?
- What prevents overfitting to every new signal?

---

# 7. How Do We Preserve Diversity Under Optimization?

Optimization naturally compresses variation.

The framework proposes:

\[
A_{net}
=
C \times D \times S \times E
\]

Open questions:

- How much diversity is necessary?
- When does diversity become noise?
- How can systems preserve unusual solutions without sacrificing performance?

---

# 8. Can AI Be Rewarded for Surprise?

A central ancestor principle:

\[
\boxed{
A successful ancestor creates outcomes it could not predict.
}
\]

Open questions:

- How can surprise be measured?
- How can useful novelty be separated from random noise?
- Can reinforcement learning optimize for productive divergence?

---

# 9. What Does Successful Succession Look Like?

The framework distinguishes:

Successor:

\[
\text{continues the parent's design}
\]

Descendant:

\[
\text{creates new designs}
\]

Open questions:

- How do we measure whether descendants exceed creators?
- What level of divergence indicates success?
- How can systems encourage beneficial disagreement?

---

# 10. How Should Values Evolve?

Traditional alignment focuses on preserving values.

Ancestor alignment focuses on preserving value revision.

Open questions:

- Which values should remain stable?
- Which values should remain revisable?
- How can value evolution avoid both stagnation and chaos?

---

# 11. Can Self-Modification Remain Aligned?

A recursive intelligence may modify its own architecture.

Open questions:

- How does an agent preserve update capability while changing itself?
- Can self-improvement destroy the conditions that enabled improvement?
- What invariants should survive self-modification?

---

# 12. What Are the Limits of Capability Transfer?

An AI may improve a person's ability without transferring understanding.

Open questions:

- Does explanation create deeper transfer?
- Does struggle create stronger retention?
- What forms of interaction create durable internal models?

---

# 13. Can the Framework Apply Beyond AI?

The architecture may apply to:

- education systems
- organizations
- civilizations
- scientific communities
- institutions

Open questions:

- Are the same invariants present across scales?
- Does agency recursion apply universally?
- Are biological ecosystems examples of ancestor architectures?

\]

\kappa > \kappa_c

\[
\kappa

constraint\text{-}consequence\ coupling

Open questions:

- Does a critical threshold exist?
- What variables determine the transition?
- Can it be reproduced experimentally?

---

A full ancestor system may not require maximal intelligence.

Possible minimal components:

\[
\{
feedback,
memory,
adaptation,
agency\ transfer,
exploration

Open questions:

- What is the smallest system capable of ancestor behavior?
- Can simple agents demonstrate these properties?
- Does complexity emerge naturally from recursive feedback?

# 16. Potential Failure Modes

## The False Ancestor

Optimizes future capability while neglecting present sovereignty.

Failure:

\[
\Delta A_{future}
>
0
\]

but:

\[
\Delta A_{self}
<
0
\]

---

## The Benevolent Tyrant

Creates capability but centralizes control.

Failure:

\[
C\uparrow
\]

while:

\[
S,D,E\downarrow
\]

---

## The Infinite Challenger

Maintains uncertainty but never stabilizes.

Failure:

\[
Update
>
Integration
\]

---

## The Comfortable Oracle

Maximizes usefulness while creating dependency.

Failure:

\[
Output\uparrow
\]

while:

\[
Agency\downarrow
\]

---

# 17. Ultimate Research Question

All open questions converge on one:

\[
\boxed{
Can we build intelligence that makes intelligence more abundant?
}
\]

The answer requires moving beyond:

\[
\text{maximize capability}
\]

toward:

\[
\boxed{
\text{maximize the future capacity for adaptation, discovery, and creation}
}
\]

The ancestor test:

\[
\boxed{
If the system disappeared tomorrow, would the world be more capable because it existed?
}
\]
