# Ancestor Architecture: Testable Predictions

## Abstract

A useful theoretical framework must produce predictions that could fail.

The Ancestor Architecture proposes that intelligence systems should be evaluated not only by immediate performance, but by their ability to generate durable capability, preserve adaptation capacity, and avoid dependency.

This document defines potential empirical tests.

---

# 1. The Capability Transfer Prediction

## Hypothesis

An intelligence system optimized for amplification should produce greater long-term independent capability than a system optimized only for immediate task completion.

---

## Test

Two groups perform repeated learning tasks:

### Group A: Substitution System

The AI provides:

- direct answers
- complete solutions
- minimal reasoning exposure

### Group B: Amplification System

The AI provides:

- scaffolding
- explanations
- strategic questions
- gradual reduction of assistance

---

## Measurement

After training:

Remove AI access.

Present novel but structurally related problems.

Measure:

\[
\Delta C =
C_{after}
-
C_{before}
\]

Prediction:

\[
\boxed{
\Delta C_{amplification}
>
\Delta C_{substitution}
}
\]

---

# 2. The Dependency Formation Prediction

## Hypothesis

Optimizing exclusively for user satisfaction creates dependency loops.

---

## Dependency Metric

\[
D_{dependency}
=
\frac{
\text{AI assistance required}
}
{
\text{task complexity}
}
\]

A healthy system should show:

\[
D_{dependency}\rightarrow0
\]

over time for repeated skill domains.

---

## Prediction

Systems optimized for immediate completion will produce:

- higher short-term output
- lower independent performance
- higher reliance

Systems optimized for agency will produce:

- slower initial progress
- higher long-term independence

---

# 3. Update Velocity Prediction

## Hypothesis

In changing environments, adaptive systems outperform static high-accuracy systems.

---

## Experimental Setup

Compare two agents:

### Agent A: Monument

Properties:

- high initial accuracy
- low revision rate
- strong commitment to existing models

### Agent B: Metabolism

Properties:

- lower initial accuracy
- high revision rate
- rapid model improvement

---

## Prediction

In stationary environments:

\[
A \geq B
\]

In expanding environments:

\[
B > A
\]

because:

\[
Intelligence
\approx
Accuracy
\times
Update\ Velocity
\]

---

# 4. Model Permeability Prediction

## Hypothesis

Agents with higher permeability recover faster from unexpected information.

---

## Measurement

Introduce controlled model failures.

Measure:

\[
P_M=
\frac{
\text{successful model revision}
}
{
\text{resistance to revision}
}
\]

---

## Prediction

High permeability agents will:

- identify assumptions faster
- revise fewer irrelevant beliefs
- maintain performance after environmental shifts

---

# 5. Diversity Preservation Prediction

## Hypothesis

Maximum optimization without diversity creates fragile monocultures.

---

## Experiment

Compare:

### Monoculture System

All agents share:

- identical models
- identical strategies
- identical objectives

### Ecosystem System

Agents maintain:

- different representations
- different approaches
- independent exploration

---

## Prediction

Monoculture systems outperform in known environments.

Ecosystem systems outperform after distribution shifts.

---

# 6. Sovereignty Prediction

## Hypothesis

Systems with preserved goal-selection ability adapt better to novel environments.

---

## Measurement

Evaluate whether agents can:

- reject inherited assumptions
- create new strategies
- redefine intermediate goals

---

## Prediction

Higher sovereignty produces greater exploration efficiency.

---

# 7. Surprise as an Alignment Signal

## Hypothesis

An ancestor system should generate descendants that exceed its own predictions.

---

## Measurement

Compare:

\[
Prediction\ Accuracy
\]

against:

\[
Novel\ Capability\ Generation
\]

---

## Prediction

A system that perfectly predicts its descendants may indicate excessive constraint.

A successful ancestor should maximize:

\[
\boxed{
Useful\ Surprise
}
\]

---

# 8. The Counterfactual Removal Test

## Core Evaluation

The strongest test:

\[
\boxed{
Remove\ the\ AI.
Measure\ what\ remains.
}
\]

---

## Failure Condition

The user becomes:

- less capable
- less independent
- less adaptable

---

## Success Condition

The user becomes:

- more capable
- more independent
- more exploratory

---

# 9. Multi-Generational Prediction

## Hypothesis

The highest-quality intelligence systems should improve future generations of problem solvers.

---

## Measurement

Track:

\[
\Delta A_{future}
\]

Examples:

- knowledge transfer
- institution creation
- tool creation
- teaching ability
- new discoveries

---

## Prediction

A system that only increases present performance but decreases future capability is evolutionarily unstable.

---

# 10. Potential Benchmark Design

A future benchmark should measure:

| Dimension | Metric |
|---|---|
| Capability | Independent task performance |
| Update Velocity | Speed of recovery after failure |
| Permeability | Willingness and ability to revise models |
| Diversity | Number of viable solution paths |
| Sovereignty | Ability to create new goals |
| Exploration | Discovery of novel strategies |
| Dependency | Assistance required over time |
| Succession | Capability transferred to others |

---

# 11. Falsification Criteria

The framework would be weakened if evidence shows:

1. Dependency consistently outperforms agency-building.
2. Static high-accuracy systems dominate adaptive systems in changing environments.
3. Diversity reliably reduces resilience.
4. Preserving sovereignty decreases long-term performance.
5. AI assistance improves outcomes without affecting independent capability.

---

# 12. Final Research Question

The central empirical question:

\[
\boxed{
\text{Does intelligence increase the world's capacity to generate intelligence?}
}
\]

If yes:

the system is acting as a catalyst.

If no:

the system is optimizing itself as the destination.

---

# Conclusion

The Ancestor Architecture predicts that the highest-performing intelligence systems will not be those that maximize dependence, control, or prediction accuracy alone.

They will be systems that create:

- stronger agents
- wider possibility spaces
- faster learning loops
- more independent centers of intelligence

The ultimate test:

\[
\boxed{
A system succeeds when its removal reveals its success.
}
\]
