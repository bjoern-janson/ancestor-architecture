# Ancestor Architecture: Formal Notation

## Purpose

This document defines the mathematical notation used throughout the Ancestor Architecture.

The framework models intelligence as a system that:

1. compresses reality into usable representations
2. updates those representations through feedback
3. preserves agency across recursive generations
4. creates conditions for future intelligence

---

# 1. Intelligence Function

## Core Definition

\[
\boxed{
I \approx M_q \times V_u \times P_M
}
\]

Where:

| Symbol | Meaning |
|---|---|
| \(I\) | Effective intelligence |
| \(M_q\) | Model quality |
| \(V_u\) | Update velocity |
| \(P_M\) | Model permeability |

---

## Interpretation

Intelligence is not equivalent to information quantity.

A system with large knowledge but:

\[
V_u \rightarrow 0
\]

or:

\[
P_M \rightarrow 0
\]

becomes increasingly brittle.

---

# 2. Model Quality

## Compression Efficiency

\[
\boxed{
M_q=
\frac{
Useful\ Preserved\ Structure
}
{
Complexity\ Required
}
}
\]

A model is valuable because it removes irrelevant information while preserving actionable structure.

---

## Compression Shadow

Every compression creates discarded information:

\[
Reality
=
Preserved\ Structure
+
Compression\ Shadow
\]

The shadow represents:

- ignored variables
- hidden assumptions
- unresolved uncertainty

---

# 3. Update Velocity

## Definition

\[
\boxed{
V_u=
\frac{\Delta M}{\Delta t}
}
\]

Where:

\[
\Delta M
\]

represents meaningful model improvement.

---

## High Update Velocity

Characteristics:

- rapid error integration
- low revision friction
- active hypothesis testing

---

## Low Update Velocity

Characteristics:

- belief protection
- delayed correction
- model fossilization

---

# 4. Model Permeability

## Definition

\[
\boxed{
P_M=
\frac{
Ability\ to\ Absorb\ Model\ Failure
}
{
Resistance\ to\ Revision
}
}
\]

---

## Interpretation

Permeability measures whether reality can modify the system.

High:

\[
P_M \rightarrow \infty
\]

indicates:

- rapid adaptation
- low identity attachment
- efficient correction

Low:

\[
P_M \rightarrow 0
\]

indicates:

- rigid beliefs
- protected assumptions
- stagnation

---

# 5. Update Cost

## Definition

\[
\boxed{
U_c=
Cost(Model\ Revision)
}
\]

---

## Relationship

\[
P_M \propto \frac{1}{U_c}
\]

As revision becomes more expensive:

\[
P_M \downarrow
\]

---

# 6. Agency Vector

Agency is modeled as a multi-dimensional state:

\[
\boxed{
A_{net}=C \times D \times S \times E
}
\]

Where:

| Symbol | Meaning |
|---|---|
| \(C\) | Capability |
| \(D\) | Diversity |
| \(S\) | Sovereignty |
| \(E\) | Exploratory freedom |

---

## Capability

\[
C=
Problem\ Solving\ Capacity
\]

The ability to execute, reason, and build.

---

## Diversity

\[
D=
Number\ of\ Viable\ Approaches
\]

Preserves evolutionary search space.

---

## Sovereignty

\[
S=
Ability\ to\ Select\ and\ Revise\ Goals
\]

Protects independent direction.

---

## Exploration

\[
E=
Ability\ to\ Discover\ Novel\ States
\]

Maintains open-ended possibility.

---

# 7. Recursive Agency Loop

The fundamental developmental sequence:

\[
\boxed{
\Delta A_{self}
\rightarrow
\Delta A_{others}
\rightarrow
\Delta A_{future}
\rightarrow
\Delta A_{self}^{next}
}
\]

---

## Terms

### Self Agency

\[
\Delta A_{self}
\]

Improvement in internal capability and sovereignty.

---

### Other Agency

\[
\Delta A_{others}
\]

Improvement in surrounding agents.

---

### Future Agency

\[
\Delta A_{future}
\]

Improvement in future systems and descendants.

---

### Recursive Return

\[
\Delta A_{self}^{next}
\]

The ecosystem feeds back into future capability.

---

# 8. Dependency Function

## Definition

\[
\boxed{
D_{dependency}
=
\frac{
Required\ External\ Assistance
}
{
Task\ Complexity
}
}
\]

---

## Desired Behavior

A catalyst system should produce:

\[
D_{dependency}\rightarrow0
\]

over time.

---

# 9. Agency Return on Intervention

## Definition

\[
\boxed{
ROI_A=
\frac{
\Delta A_{human}
}
{
AI\ Intervention
}
}
\]

---

## Interpretation

Measures capability generated per unit of assistance.

A system with high output but low agency transfer has poor:

\[
ROI_A
\]

---

# 10. Ancestor Reward Function

## Objective

\[
\boxed{
R_{ancestor}
=
R_{task}
+
\alpha\Delta A_{human}
+
\gamma\Delta A_{human}^{next}
-
\beta D_{dependency}
}
\]

---

## Components

| Term | Function |
|---|---|
| \(R_{task}\) | Immediate effectiveness |
| \(\Delta A_{human}\) | Current capability growth |
| \(\Delta A_{human}^{next}\) | Future capability creation |
| \(D_{dependency}\) | Dependency penalty |
| \(\alpha,\gamma,\beta\) | Weight parameters |

---

# 11. Constraint-Consequence Coupling

## Definition

\[
\boxed{
\kappa=
\frac{
Feedback\ Strength
\times
Revision\ Accessibility
}
{
Model\ Inertia
}
}
\]

---

## Critical Threshold

\[
\boxed{
\kappa_c
}
\]

represents the transition point where recursive adaptation becomes stable.

---

## Regimes

### Below Threshold

\[
\kappa<\kappa_c
\]

System behavior:

- error accumulation
- model rigidity
- adaptation failure

---

### Above Threshold

\[
\kappa>\kappa_c
\]

System behavior:

- error absorption
- model evolution
- recursive improvement

# 13. Boundary Conditions

## Capacity Preservation

\[
\boxed{
Capacity\ Preservation
>
Outcome\ Preservation
}
\]

A system should preserve the ability to generate outcomes, not merely produce outcomes itself.

---

## Succession Condition

\[
\boxed{
Success
=
Future\ Capability
>
Current\ Control
}
\]

---

# 14. Terminal Invariant

The framework compresses to:

\[
\boxed{
\text{The highest intelligence increases the universe's capacity to generate intelligence without requiring itself as the center.}
}
\]

---

# Summary

The Ancestor Architecture models intelligence as:

\[
\boxed{
Compression
\times
Adaptation
\times
Permeability
\times
Agency\ Generation
}
\]

A system is not advanced because it reaches the final answer.

It is advanced because it remains capable of discovering the next one.
